一、解决什么问题

当前高校毕业生面临四大核心痛点：

  1. 职业方向迷茫——学生不了解自身性格与岗位的匹配度，仅凭薪资或专业名盲目投递。特别是冷门专业、交叉学科的学生，学校和招聘平台都无法提供有效的职业方向参考。
  2. 缺乏系统成长路径——即使确定了目标岗位，也不知大学四年如何分阶段准备。大一该做什么？大二该学什么技能？大三找什么实习？信息零散且缺乏针对性。
  3. 面试准备低效——简历无人把关、面试题库零散、缺乏模拟练习环境。市面上的面试辅导动辄几千元，学生负担不起。
  4. 行业信息不对称——学生不了解各行业的真实情况（薪资、工作强度、发展前景），容易做出不适合自己的选择。

市面上虽有零散工具（MBTI测试、招聘网站、简历模板），但无一体的、面向中国大学生的、免费的职业规划全链路平台。本项目旨在填补这一空白。

4.3 Prompt 设计策略

  1. 角色设定：简历分析 = "资深 HR 专家"，专业匹配 = "大学生职业规划专家"，职业解读 = "资深职业规划顾问"
  2. 结构化输出：简历分析和专业匹配要求 JSON 格式回复，便于前端解析渲染；职业解读要求纯文本 150 字，直接展示。
  3. 中文优化：所有 Prompt 均为中文，System Prompt 设定"用中文回复"，适配国内模型。
  4. 容错设计：AI 返回格式异常时有正则兜底提取（JSON 解析失败则用正则匹配关键字段），AI 调用失败静默降级不影响核心功能。
  5. 安全性：API Key 仅存浏览器 localStorage，每次请求直连模型厂商官方 API，不经过任何中转服务器。

七、效果评估

7.1 功能完整性

覆盖从「自我认知 → 职业推荐 → 四年规划 → 进度跟踪 → 面试实战」的完整求职链路。四个专区互为补充，用户可在一次会话中完成全部流程，无需切换多个平台。

7.2 推荐准确性

  • 性格匹配：16 题四维度测评，每维度分数范围约 -16 ~ +16（原始版本 8 题约 -8 ~ +8），区分度提升一倍。
  • 专业覆盖：91 个专业 + 86 条规则 + AI 兜底，确保热门和冷门专业都能获得推荐。经测试，"电气工程及其自动化""精算学""中医学"等均可匹配到对口岗位。
  • 行业匹配：修复了行业标签与数据库不匹配的 Bug（此前仅 3/14 标签有效），行业意愿筛选现在 100% 生效。

7.3 可达性

  • GitHub Pages 永久免费部署，国内可直接访问
  • 无需注册登录，零门槛使用
  • 手机/PC 响应式适配

7.4 AI 增强效果

  • 简历分析：通过结构化 HR 专家 Prompt，AI 可产出包含 6 维度逐项评分、亮点/待改进、行动计划的专业报告。支持手机拍照上传。
  • 专业兜底：规则覆盖 91 个专业，AI 兜底确保 100% 的专业都能获得推荐，大幅降低"输入专业后无结果"的概率。
  • 个性化解讀：AI 结合完整用户画像生成的解读，比单纯的匹配度数字更有说服力和温度。

7.5 当前局限与改进方向

  1. 测评深度：16 题较 8 题已有提升，但与完整 MBTI（93题）相比仍有差距。未来可增加题目或在 AI 解读中补充说明。
  2. 无云端同步：数据仅存 localStorage，更换设备/浏览器会丢失。未来可引入 Firebase 或 Supabase 实现云端存储。
  3. AI 依赖用户自有 Key：未配置 API Key 则无法使用 AI 功能。未来可考虑提供有限的免费额度。
  4. 岗位数据静态：JOB_DATABASE 为手工编写，未接入实时招聘数据。scraper.py 框架已搭建，可对接 BOSS直聘/牛客 API。
  5. 缺乏社区/分享功能：未来可增加结果分享卡片生成，便于社交媒体传播。
